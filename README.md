#  Student Performance Analysis & Prediction

An end-to-end data analysis and machine learning project focused on understanding and predicting student academic performance.

##  Project Overview

This project analyzes student performance data to identify the key factors that influence exam scores and provide meaningful insights that can help improve students' academic outcomes.

The project combines **Power BI dashboards**, **data preprocessing**, **exploratory analysis**, and **machine learning models** to provide both visual and predictive insights.

## Power BI Dashboards

The project includes three interactive dashboards:

### 1. General Overview
Provides a high-level overview of student performance, including:
- Total number of students
- Average study hours
- Average attendance
- Average exam score
- Exam grade distribution
- Gender distribution
- Relationship between attendance, study hours, and exam scores

### 2. School Impact
Analyzes how school-related factors affect student performance, including:
- School type
- Teacher quality
- Learning disabilities
- Study hours and attendance
- Tutoring sessions

### 3. Life Impact
Explores external and personal factors affecting academic performance, including:
- Family income
- Tutoring sessions
- Motivation
- Access to educational resources
- Parental education and involvement
- Sleep hours

##  Machine Learning

The project also evaluates **Classification** and **Regression** models using school-related and home-related features.


##  Key Insights

- Attendance and study hours show a positive relationship with exam performance.
- Teacher quality is an important school-related factor.
- Students with learning difficulties may require additional support.
- Tutoring appears beneficial up to a certain point, with performance peaking around six sessions.
- Motivation, sleep, family income, and parental involvement are among the factors explored in the analysis.
